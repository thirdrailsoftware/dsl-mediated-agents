# DSL-mediated Agents

> __DSL-mediated Agents__ are AI agents that read and write documents in a well-defined domain-specific language (DSL)
> rather than free-form text, so that their work can be formally validated, reviewed by human experts, turned into
> artifacts by deterministic generators, or passed cleanly to downstream agents.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23587494.svg)](https://doi.org/10.5281/zenodo.23587494)

AI agents reason in a non-deterministic way, which makes their free-form output hard to check, review, reproduce, and
hand off. The idea here is to give the agent a precise, domain-specific language to work in, so that machines can
validate what it writes, domain experts can review it in their own terms, and deterministic tools can turn the approved
result into deliverables.
